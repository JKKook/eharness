세션 (제목)
Claude가 대화에 붙인 제목. 없으면 마지막 질문, 그것도 없으면 레지스트리 이름. 작은 글씨의 이름(예: ethan-6c)은 터미널 statusline의 [이름]과 같다.
터미널
그 세션이 떠 있는 cmux 워크스페이스(사이드바 위에서 n번째)와 탭 제목, 없으면 tty.
상태
작업 중 = 응답 생성 또는 도구 실행 중 · 대기 = 사용자 입력 기다림 · 종료 = 프로세스 없음.
컨텍스트
대화 창(1M 토큰) 중 지금 차 있는 비율. ~가 붙으면 근사치. 80% 이상은 빨강.
비용 / 토큰
세션 누적 API 비용(USD) / 입력 = 새로 과금된 입력 토큰, 캐시 = 프롬프트 캐시에서 읽은 토큰(저렴), 출력 = 모델이 생성한 토큰. k = 천.
턴 / 가동
사용자가 질문을 제출한 횟수 / 세션 시작 후 경과.
활동 타임라인
연한 파랑 = 한 턴(질문 제출 → 응답 완료), 진한 파랑 = 도구 실행 구간, 빨간 마름모 = 도구 실패. 점선 = 지금.
분할 보기
살아있는 세션을 최대 24칸으로 화면에 맞춰 배치. 칸마다: 터미널 #, 제목, 통신 그룹 배지, 상태, 지금 실행 중인 도구와 경과(또는 마지막 활동 시각), 마지막 질문, 활동 그래프, 컨텍스트·비용·턴. 작업 중 세션이 앞에 오고 왼쪽 안쪽 파란 띠.
분할 칸의 활동 그래프
전체 화면의 활동 타임라인을 세션 하나만 잘라 넣은 것. 연한 띠 = 턴(질문 제출 → 응답 완료), 진한 막대 = 도구 실행 구간, 빨강 = 실패한 도구 호출, 점선 = 지금. 왼쪽 끝이 시간 범위 시작, 오른쪽 끝이 지금.
통신 그룹
세션 간 메시지(SendMessage ↔ cross-session-message)를 트랜스크립트에서 읽어, 살아있는 세션끼리 주고받은 적이 있으면 하나의 그룹(G1, G2…)으로 묶는다. 분할 칸의 테두리 색, 목록·타임라인의 색점이 그룹 색. 배지 ↔ G1 · 2 = 그룹 번호와 살아있는 상대 수; hover에 상대별 보냄/받음 횟수와 종료된 상대. 이벤트 목록엔 "메시지 전송 → 상대"로 표시.
세션 통신 그래프
노드 = 세션(테두리색 = 통신 그룹, 파란 점 = 작업 중, 점선 = 지금은 종료된 상대), 화살표 = 메시지 방향, 숫자·굵기 = 누적 횟수, 주황 = 선택한 시간 범위 안에 실제로 전송된 메시지. 2D는 같은 통신 그룹을 나란히 놓고 그룹 띠로 묶은 아크 다이어그램, 3D는 그룹마다 섬(원판)을 두고 공중의 호로 메시지 경로를 그린 뷰(드래그 회전·휠 줌·자동 회전). 3D의 ▶ 재생은 선택한 시간 범위의 메시지를 시간 순으로 호를 따라 움직이는 펄스로 재생한다(배속·슬라이더 스크럽, 호 굵기·숫자는 그 시점까지 누적; 슬라이더 끝 = 라이브, 라이브에선 방금 전송된 메시지가 자동으로 펄스). 통신 기록이 없는 세션은 기본 숨김.
수동 그룹 / 통신 링크
통신 그래프의 관리에서 세션을 골라 이름 있는 그룹으로 묶거나(테두리·그래프에 그룹 이름 표시) 두 세션을 통신 관계로 등록(점선 화살표)할 수 있다. 서버에 저장되어 어디서 열어도 같고, 세션이 재시작되면 이름으로 다시 매칭.
분할의 폴더 필터
분할 화면 상단 버튼으로 cmux 사이드바 폴더(그룹) 기준 필터. "기타" = 폴더 없음/cmux 밖.
접기
