# cctv-dispatch — 리더 → 자식 지시 분배

사용자가 지정한 지시를 등록된 자식 세션들에게 나눠 보낸다.
전송은 **이 세션 자신의 SendMessage 도구**로만 한다 (수집기·훅 경유 금지).

## 절차

1. **자식 확인** — `bash ~/.claude/skills/cctv-register/register.sh status` 를 실행해
   `children`의 이름을 얻는다. ListAgents로 해당 이름들이 실제 살아있는지 교차 확인한다.
   - children이 비었거나 comm 스킬이 없으면: 사용자에게 대상 세션 이름을 직접 확인하고,
     원하면 `register.sh child <이름>`으로 등록부터 제안한다.
   - "자식 1번/2번" 같은 서수 지칭은 children 배열 순서로 해석하되, **발송 전에 이름을 명시해
     사용자에게 매핑을 보여준다** (1번=<이름A>, 2번=<이름B>).
2. **분배** — 자식마다 SendMessage 1건. 메시지 형식:
   ```
   [리더 지시 — <리더 이름>]
   작업: <사용자가 지정한 지시>
   완료 기준: <있으면 명시, 없으면 "작업 완료 후">
   회신: 완료 시 SendMessage로 <리더 이름>에게 결과 요약과 잔여(미해결 N건 · 검증 X/Y)를 보내라.
   ```
3. **발송 대장 보고** — 사용자에게 표로: 대상 이름 | 보낸 지시 | 발송 성공 여부.
4. **회신 수신** — 자식의 회신은 턴 경계에 cross-session-message로 도착한다. 도착하면 요약해
   사용자에게 전달한다. 회신이 오래 없으면 cctv-status(있다면)로 자식 상태를 확인해 보고한다.

## 금지

- 사용자가 명시하지 않은 작업을 만들어 보내는 것.
- 자식으로 등록되지 않은 세션에 대한 브로드캐스트 (지명된 대상에게만).
- 긴 지시문 — 자식 세션의 컨텍스트를 소모하므로 지시는 간결하게, 큰 자료는 파일 경로로 전달.
