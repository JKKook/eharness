# cctv-dispatch — 리더 → 자식(팀원) 지시 분배

사용자가 지정한 지시를 등록된 자식(팀원) 세션들에게 나눠 보낸다. "자식"과 "팀원"은 같은 대상이다
(관제 계층의 child = cmux 사이드바의 팀원). 전송은 **이 세션 자신의 SendMessage 도구**로만 한다
(수집기·훅 경유 금지).

## 리더 제한 (선행 조건)

이 스킬은 **리더 세션에서만** 동작한다. 절차 1에서 `children`이 비어 있으면 발송하지 말고
이렇게 보고 후 중단한다:
> "이 세션은 리더가 아닙니다 — 등록된 자식(팀원)이 없습니다. 먼저
> `bash ~/.claude/skills/cctv-register/register.sh child <세션 이름>` 으로 팀원을 등록해 주세요."
등록되지 않은 세션에 이름만 듣고 직접 보내는 폴백은 **하지 않는다** (계층이 곧 권한이다).

## 절차

1. **자식(팀원) 확인** — `bash ~/.claude/skills/cctv-register/register.sh status` 를 실행해
   `children`의 이름을 얻는다. 비어 있으면 위 리더 제한대로 중단.
   ListAgents로 해당 이름들이 실제 살아있는지 교차 확인하고, 죽어 있는 팀원은 제외 후 보고한다.
   - "자식 1번/2번"·"팀원 1/2" 같은 서수 지칭은 children 배열 순서로 해석하되, **발송 전에
     이름을 명시해 사용자에게 매핑을 보여준다** (1번=<이름A>, 2번=<이름B>).
2. **분배** — 자식(팀원)마다 SendMessage 1건. 메시지 형식:
   ```
   [리더 지시 — <리더 이름>]
   작업: <사용자가 지정한 지시>
   완료 기준: <있으면 명시, 없으면 "작업 완료 후">
   회신: 완료 시 SendMessage로 <리더 이름>에게 결과 요약과 잔여(미해결 N건 · 검증 X/Y)를 보내라.
   ```
3. **발송 대장 보고** — 사용자에게 표로: 대상 이름 | 보낸 지시 | 발송 성공 여부.
4. **회신 수신** — 팀원의 회신은 턴 경계에 cross-session-message로 도착한다. 도착하면 요약해
   사용자에게 전달한다. 회신이 오래 없으면 cctv-status(있다면)로 팀원 상태를 확인해 보고한다.

## 금지

- **리더가 아닌 세션에서의 발송** (children 비어 있음 = 중단·안내만).
- 사용자가 명시하지 않은 작업을 만들어 보내는 것.
- 자식(팀원)으로 등록되지 않은 세션에 대한 발송·브로드캐스트 (등록된 대상에게만).
- 긴 지시문 — 자식 세션의 컨텍스트를 소모하므로 지시는 간결하게, 큰 자료는 파일 경로로 전달.
