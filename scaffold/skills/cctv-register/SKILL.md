# cctv-register — 세션 관제 등록

이 세션(또는 이름으로 지정한 다른 세션)을 eharness 관제의 리더/팀원 계층·세션 그룹에 등록한다.
등록은 표시용 메타데이터다 — 어떤 게이트·차단도 없고, 대시보드·statusline·cmux 사이드바 표시에만 쓰인다.

## 실행 방법

동봉된 스크립트를 Bash로 실행한다 (스킬 디렉터리 기준):

```bash
bash ~/.claude/skills/cctv-register/register.sh <명령> [인자]
```

| 명령 | 뜻 |
|---|---|
| `parent <이름>` | 이 세션을 `<이름>` 세션의 **팀원(자식)** 으로 등록 |
| `child <이름>` | `<이름>` 세션을 이 세션의 자식으로 — 즉 **이 세션이 리더** |
| `clear` | 이 세션의 부모 관계 해제 |
| `group <이름>` | 이 세션을 세션 그룹 `<이름>`에 배정 (세션당 1그룹) |
| `ungroup` | 세션 그룹 해제 |
| `status` | 자기 행(sid·parent·children·sgroup) 확인 — 등록 후 검증용 |

`<이름>`은 대시보드에 보이는 세션 이름(레지스트리 name) 또는 등록된 표시 이름. 상대 세션이
아직 안 떠 있어도 이름으로 저장되고, 세션이 뜨면 이름 재매칭으로 연결된다.

## 절차

1. 사용자 요청을 명령으로 변환해 실행한다 (예: "나는 ethan-lead의 팀원" → `parent ethan-lead`).
2. 응답 JSON에 `"ok": true`(또는 manual 문서)가 오는지 확인한다. `409`면 순환 계층 — 사용자에게 알린다.
3. `status`로 반영을 확인하고 결과를 한 줄로 보고한다 (수집기 재계산에 ~3초 걸릴 수 있음).

## 주의

- 수집기(127.0.0.1:7477)가 죽어 있으면 실패한다 — `eharness collect --status` 확인을 안내.
- 등록 데이터는 관제 표시용일 뿐이므로, 실패해도 작업 자체는 계속 진행한다.
